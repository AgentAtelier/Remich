# Remich

**The Rust bridge** of Schmelz: engine-free Rust simulation cores running inside the Godot game,
through Rust's Godot binding (`gdext`), with rebuilds fast enough to work with. Remich owns the
bridge (building, loading, calling, passing data), not the behaviour: what an inhabitant wants
belongs to [Munshausen](https://github.com/AgentAtelier/Munshausen), the weather to
[Eisleck](https://github.com/AgentAtelier/Eisleck), plants' life to
[Grengewald](https://github.com/AgentAtelier/Grengewald).

Named after the Moselle town whose bridge crosses from Luxembourg to Germany.

The plan — the destination and phase 1 (anvil's scorer chooses what Ada does next) — is [docs/PLAN.md](docs/PLAN.md).
